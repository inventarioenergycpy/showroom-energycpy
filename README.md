# ⚡ Energy CPY — Showroom Oficial de Inversiones Estratégicas 2026

![Energy CPY Showroom](assets/images/logo_energy_cpy_header.png)

Plataforma web de alto impacto para la exhibición, análisis y consulta ejecutiva de proyectos de inversión estratégica (Energía Solar MATER, Pesca Industrial en Patagonia, Infraestructura Energética e Inmobiliaria REIT) en Argentina 2026.

🌐 **Demo Live (GitHub Pages)**: [https://inventarioenergycpy.github.io/showroom-energycpy/](https://inventarioenergycpy.github.io/showroom-energycpy/)

---

## 🎯 Características Principales

- **Estética & Maquetación Premium**: Paleta cromática corporativa Dark Mode (`#090d16`), tarjetas con efecto Glassmorphic, detalles en dorado corporativo (`#e2b714`), Cyan (`#38bdf8`) y verde sostenibilidad (`#10b981`).
- **Visor Modal Interactivo de Diapositivas**: Navegación táctil y por teclado (`←`, `→`, `Esc`) para cada presentación PDF procesada a imágenes HD.
- **Filtros Dinámicos por Sector**: Categorización instantánea (`Energía Solar`, `Pesca Industrial`, `Infraestructura Salta`, `Estrategia REIT`).
- **Descargas Directas & Contacto Ejecutivo**: Acceso directo al PDF oficial original y botón directo a consulta ejecutiva por WhatsApp.
- **Buenas Prácticas GitHub Pages**: Almacenamiento híbrido optimizado (< 25 MB en activos locales, imágenes comprimidas, URLs URL-safe).

## 💻 Desarrollo Local

Para ejecutar el Showroom en tu entorno local:

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/inventarioenergycpy/showroom-energycpy.git
   cd showroom-energycpy
   ```

2. Abrir `index.html` en tu navegador predeterminado o servidor web local (ej. Live Server, `npx serve`).
